# Segmented control

A pill of options with a white thumb that slides to the active one.

- Track: full pill, 4px padding, black 5% (white 10% on dark). Options 32px tall, 13px medium, muted when inactive.
- One white thumb (soft two-layer shadow) shared across options via layoutId, moved with the snappy spring (520/34). Text colour cross-fades.
- Labels can carry a badge (e.g. an `accent` "-20%" chip on Yearly).
